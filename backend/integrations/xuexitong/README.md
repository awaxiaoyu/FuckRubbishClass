# 学习通桌面接入

`app.adapters.chaoxing.ChaoxingAdapter` 是本仓库独立实现的 Playwright 适配器，
不包含或注入 [chaolucky18/xuexitongScript](https://github.com/chaolucky18/xuexitongScript) 的源码。
保留该链接作为最初的项目来源引用。

## 使用

1. 用应用的 Python 环境安装 `requirements-desktop.txt`，默认使用本机 Edge。
2. 进入左下角“设置 → 学习通”，选择浏览器、会话保存与播放参数并保存。
3. 在学习通工作区点击“登录”，在应用管理的窗口中扫码、登录或完成验证码。
4. 应用验证私有课程服务可访问后才返回成功，并自动同步课程（含课程文件夹）。
5. 选择课程，点击“播放选中视频任务”。可以多选课程顺序执行，用“停止任务”暂停。

窗口由适配器管理，应用可接收它的 Cookie 和页面状态；“打开会话窗口”也复用该窗口。
默认浏览器之前的网页登录不会自动导入。遇 HTTP 403、登录失效或未知课程格式会显示错误，
不会将网页打开或空响应伪装成登录成功。点击“清除会话”关闭窗口并删除本机保存的状态。

## 功能范围

- 课程信息规范化为课程、班级、CPI 组合标识，避免同名课程或不同班级冲突。
- 章节导航、识别已完成章节、跨 frame 原生视频播放、实际秒数进度、静音与速度设置。
- 取消任务时暂停媒体，保留浏览器现场，不终止课堂派服务。
- 课件、章节测验、考试、签到和弹题需手动处理；未识别到视频的章节明确列为待处理。
- 不修改视频当前时间、不伪造完成状态或平台回报；播放结束不代表所有任务点已完成。
- AI 设置当前用于知到 AI 课程，不能据此宣称学习通测验已接入 AI 自动答题。

Cookie / localStorage 保存在 `.sessions/chaoxing.json`，默认排除 Git。
浏览器选 `msedge` 或 `chrome` 时使用已有安装；选 `chromium` 时需先运行
`python -m playwright install chromium`。

## 验证边界

核心测试覆盖认证失败、课程解析、会话保存、设置校验与取消信号。
本地模拟站点配合真实 Edge headless 验证登录回传、文件夹课程、连续视频、播放进度、
停止后暂停与会话恢复。真实平台仍需用户在登录窗口完成扫码，学校定制课程页面可能需要进一步适配。
